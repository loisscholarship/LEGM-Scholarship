# Lois Ellen Gibbs-Scholarship Project

An interactive web application built to streamline scholarship tracking and application management. Developed responsive UI layouts with JavaScript and custom CSS to deliver clean, dynamic user experience.
---

##  Features

* **Scholarship Tracking:** Dynamically view and organize open scholarship opportunities.
* **Interactive Filtering:** Filter available awards based on eligibility criteria, deadlines, and funding amounts.
* **Responsive Design:** Optimized layout ensuring seamless navigation across mobile, tablet, and desktop viewports.
* **Clean UI/UX:** User-focused, accessible interface crafted with modern CSS styling.

---

##  Tech Stack & Tools

* **Frontend:** HTML5, CSS3, JavaScript
* **Development Environment:** Visual Studio Code 
* **Version Control:** Git & GitHub
